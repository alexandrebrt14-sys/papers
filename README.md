# Papers: metodologia e dados da pesquisa inicial

A coleta desta pesquisa encerrou em 11/09/2026. A higienização de 15/10/2026 preservou o banco final, os manuscritos e as referências, desativou o GitHub Actions e removeu os artefatos temporários autorizados.

- [Roadmap científico e metodologia](ROADMAP_METODOLOGIA.md).
- [Dados finais, recortes e integridade](DADOS_FINAIS.md).
- [README e instruções históricas](README_HISTORICO.md).
- [Preprint corrigido no Zenodo](https://doi.org/10.5281/zenodo.22711743).

O banco final contém 92.064 respostas. O artigo corrigido utiliza um recorte de 91.392; a documentação de dados explica a diferença e seus limites.

[PesquisaGeo2027](https://github.com/alexandrebrt14-sys/PesquisaGeo2027) continua ativo. Seu banco, armazenamento, workflows e serviços compartilhados foram preservados. Este repositório mantém o acervo da pesquisa anterior, sem coleta automática.
